# 筋トレ記録

ブラウザで動く筋トレ記録アプリです。記録はお使いの端末のブラウザ内にだけ保存され、外部には送信されません。

## 機能
- 種目・重量・回数のセット記録(前回の記録を表示、タップで入力)
- 休憩タイマー、自己ベスト(PR)の検出と一覧
- 履歴のカレンダー表示、種目ごとの成長グラフ
- ルーティン登録、種目メモ・セットメモ
- 鍛えた部位の人体図による可視化
- JSON の書き出し・読み込み(機種変更前のバックアップに)

## スマホで使う
iPhone は Safari でページを開き、共有ボタンから「ホーム画面に追加」を選びます。

## 手元で動かす
```bash
python3 -m http.server 8001
```
http://localhost:8001 を開きます。
